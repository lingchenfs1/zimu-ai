## 字幕AI v1.1.0

根据第一版的实测反馈改进。

### 修复
- **第一次请求权限时卡住**：系统音频捕获改在后台线程启动，等待「录制系统音频」授权时界面不再冻结，并会提示去哪里授权。
- **菜单栏「退出」无法关闭软件**：退出前先在后台停止音频捕获（最多等 2 秒），并加了兜底，保证能退出。

### 改进
- **翻译跟得上识别**：一句话还没说完就开始翻译（实时译文），整句结束时直接复用；Apple 本地翻译改为批量翻译，云端翻译支持同时翻译多句；积压时优先翻译最新的句子。
- **多语言自动识别**，在 设置 › 识别 中切换：
  - Apple 本地识别（多语言自动切换）：勾选 2～4 种语言，本地同时识别并自动切换。
  - WhisperKit 本地识别：自动检测近百种语言，首次需下载模型（支持 hf-mirror.com 镜像）。
  - OpenAI 兼容云端识别：原声语言选「自动检测」。
- 翻译会按识别出的语言选择源语言；云端翻译新增「同时翻译句数」和「额外请求参数」（可关闭 Qwen3 等模型的思考）。
- 下载 Apple 语音模型时显示进度。

### 安装
与 v1.0.0 相同：下载 `ZimuAI-1.1.0.dmg`，拖到「应用程序」；未公证版本第一次打开请右键 → 打开。
系统要求：macOS 26 (Tahoe) 及以上。
