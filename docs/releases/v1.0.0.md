## 字幕AI v1.0.0

第一个版本。这是一个 macOS 菜单栏应用：识别 Mac 上正在播放的声音，实时翻译后显示在可调透明度的悬浮字幕窗里。

### 系统要求
macOS 26 (Tahoe) 及以上。

### 安装
1. 下载下方的 `ZimuAI-1.0.0.dmg`，打开后把 **ZimuAI** 拖到「应用程序」文件夹。
2. 这个版本没有用 Developer ID 签名公证，第一次打开会提示“无法验证开发者”。可以在「应用程序」里右键点击 ZimuAI → 打开 → 打开，或者在终端运行：
   ```bash
   xattr -dr com.apple.quarantine /Applications/ZimuAI.app
   ```
3. 点击菜单栏的字幕图标 → **开始字幕**（`⌃⌥S`）。第一次开始时请允许「录制系统音频」权限。

### 主要功能
- 捕获全部系统音频，也可以只捕获某个应用
- 语音识别：Apple 本地识别（离线），或 OpenAI 兼容的云端识别
- 翻译：Apple 本地翻译（离线），或任意 OpenAI 兼容服务（OpenAI / DeepSeek / 通义千问 / Kimi / 智谱 / Ollama 等）
- 悬浮字幕窗：能显示在全屏视频上方；双语 / 仅译文 / 仅原文；背景透明度、字号、颜色可调；锁定后鼠标点击穿透
- 全局快捷键 `⌃⌥S` / `⌃⌥L` / `⌃⌥H`；导出 SRT；开机启动；API Key 保存在钥匙串中
