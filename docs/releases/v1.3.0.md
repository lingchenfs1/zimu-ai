## 字幕AI v1.3.0

根据 v1.2.0 的实测反馈改进：识别更准，API 翻译不再出现思维链。

### 识别更准
- **识别模式**（设置 › 识别）：新增「准确优先」（默认）和「速度优先」。准确优先下同音字、专有名词错得更少；每句会晚一点定稿，但识别中的文字仍然实时显示。
- **断句更完整**：说话中间稍有停顿（1.8 秒内）不再被切成两句；长句超过 10 秒时优先在逗号等停顿处切分，不再从词中间断开。
- **专有名词**：填写人名、品牌、术语，AI 翻译和 AI 校对会按这些写法翻译和改正，云端识别也会参考。
- **纠错替换**：一行一条「识别结果 → 正确写法」（例如 `克劳德 → Claude`），对所有识别引擎生效，Apple 本地识别也能用。
- **用 AI 校对识别文字**（设置 › 翻译，使用 OpenAI 兼容服务时可选）：翻译主目标语言时让模型顺便改正识别错的字，字幕、导出的 SRT 都显示校正后的原文。不增加请求次数；改动过大时自动保留原识别结果。

### API 翻译：不再出现思维链，提示词已调好
- **自动关闭模型思考**（默认开启）：按服务自动附加关闭思考的参数——Ollama / LM Studio `reasoning_effort: none`，通义千问 / 硅基流动 `enable_thinking: false`，智谱 / 豆包 `thinking: disabled`，Qwen3 在提示词末尾加 `/no_think`。服务不支持时自动去掉重试。
- **过滤思考过程**：无论模型是否关闭思考，`<think>…</think>`、只输出结束标签的推理内容、gpt-oss 的分析频道都会被过滤，流式输出在思考结束前也不会显示到字幕上。
- **内置翻译提示词重新调整**：说明原文来自实时语音识别（可能是半句、有同音错字），只输出译文、不解释，字幕里的问句只翻译不回答；按目标语言使用合适的标点和口语风格。
- **翻译场景**：通用 / 影视剧对白 / 课程讲座 / 新闻访谈 / 游戏直播，自动追加对应的风格要求；可以展开查看实际发送给模型的提示词。
- 模型名看起来是推理模型（如 deepseek-r1、qwq）时会提示更换。

### 安装
下载 `ZimuAI-1.3.0.dmg`，拖到「应用程序」；未公证版本第一次打开请右键 → 打开。
系统要求：macOS 26 (Tahoe) 及以上。
