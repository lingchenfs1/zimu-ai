## 字幕AI v1.2.0

根据 v1.1.0 的实测反馈改进。

### 修复
- **拖动缩放字幕窗失败**：字幕窗解锁后，四条边和四个角都可以拖动调整大小（鼠标移上去会显示缩放光标）；缩放不再被字幕背景挡住，也不会误触发移动。

### 新功能
- **同时翻译成多种语言**：在 设置 › 翻译 的「同时翻译成」中，主目标语言之外可以再选最多 2 种语言。每句字幕会分别翻译成这些语言，依次显示在主译文下方（字号介于主译文和原文之间）。
  - 实时翻译、Apple 本地翻译语言包检查（每种语言单独显示状态和下载按钮）、「测试翻译」和导出 SRT 都支持多种译文。
  - 使用 Apple 本地翻译时，每种目标语言都需要下载语言包；使用云端翻译时，调用次数按语言数倍增。
- 「演示字幕」在设置了其他目标语言时会多显示一行示例译文，方便预览样式。

### 安装
下载 `ZimuAI-1.2.0.dmg`，拖到「应用程序」；未公证版本第一次打开请右键 → 打开。
系统要求：macOS 26 (Tahoe) 及以上。
