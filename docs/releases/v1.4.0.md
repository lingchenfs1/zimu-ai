## 字幕AI v1.4.0

新增**软件内在线更新**。

### 在线更新
- 启动时和每天自动检查一次新版本（设置 › 更新与关于 › 自动检查更新，可以关闭）。
- 发现新版本时，菜单栏面板顶部会提示，点 **更新** 即可下载、校验、安装并自动重启；点 **详情…** 可以查看更新说明、跳过这个版本或下载安装包手动安装。
- 正在显示字幕时，安装前会先确认。
- 安装前会校验文件的 SHA-256、应用标识、版本号和代码签名，并确认新版本与当前版本使用同一签名证书；任何一项不通过都不会安装。
- 只访问 GitHub 上的公开发布页，不上传任何数据。

### 签名
- 从这个版本开始，安装包使用固定的签名证书签名。以后在线更新后，「录制系统音频」权限一般会保留。

### 安装（这一次需要手动安装）
1. 下载 `ZimuAI-1.4.0.dmg`，把 ZimuAI 拖到「应用程序」文件夹（覆盖旧版本），并从「应用程序」里打开。
2. 第一次打开如果提示“无法验证开发者”：先关闭提示，到 系统设置 › 隐私与安全性，在页面下方点「仍要打开」。
3. 签名证书变了，系统会把它当成新应用：需要重新允许一次「录制系统音频」（可以先在 系统设置 › 隐私与安全性 › 屏幕与系统录音 中删掉旧的「字幕AI」）；读取钥匙串里保存的 API Key 时，可能会要求输入登录密码，请点「始终允许」。
4. 以后的版本就可以在软件内更新了。

系统要求：macOS 26 (Tahoe) 及以上。
