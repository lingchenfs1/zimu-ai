# zimu-ai（字幕AI）

一个 macOS 菜单栏应用：自动识别 Mac 本地正在播放的音频，用 AI 实时翻译成指定语言，并以**可调透明度的悬浮窗**显示，就像影片的外挂字幕。

- 系统要求：macOS 26 (Tahoe) 及以上
- 语音识别：本地 Apple SpeechAnalyzer（默认），可切换 OpenAI 兼容的云端识别
- 翻译：Apple 本地翻译，或任意 OpenAI 兼容服务（OpenAI / DeepSeek / 通义 / Ollama 等）

项目正在开发中，开发计划与进度见 [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md)。
